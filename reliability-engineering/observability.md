**Logs, Metrics, Traces**

**Traces:**
- What they are: Data representing the journey of a single request or 
transaction as it travels through a distributed system.

**Metrics:**
- What they are: Numerical data measured over time (e.g., CPU usage, 
error rates, request latency).

**Logs:**
- What they are: Recorded, timestamped events or messages (text or structured).


- A typical workflow involves:
    - Metric alerts on a spike in errors.
    - Trace identifies which service/endpoint is failing.
    - Log provides the specific error message to fix the bug.
